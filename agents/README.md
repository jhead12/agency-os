# Agent personas

Sales personas from [agency-agents](https://github.com/msitarzewski/agency-agents)
(MIT, see `LICENSE-agency-agents`), copied unmodified from the `sales/` folder at
commit `59635e0008a9a06866e3988fd0c21b1dbcaf92a7`.

They are system prompts for the built-in "Ask an agent" panel on the prospect
page (`core/agents.py`). Drop another persona file here (same frontmatter:
`name`, `description`, `emoji`) and it appears in the panel; which tasks each
persona offers is set in `core/agents.py`.
