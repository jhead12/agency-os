From your own terminal (Railway or your computer)

    
The same commands run outside the browser. Create a CLI key under Account → Command console → Use it from your own terminal, then in a checkout of agency-os (or railway ssh):

    
python3 agency_os.py connect --url {{ site_url }} --key aos_cli_...
python3 agency_os.py remote help                 # this list
python3 agency_os.py remote search-prospects --q "food bank" --limit 5
python3 agency_os.py remote                      # interactive
