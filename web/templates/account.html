Connect an AI app (MCP)

Let an AI app such as Rook, Hermes Agent, Claude Desktop or Claude Code work with your agency-os data. It acts as you, with your permissions, and you can disconnect it at any time below.

Using Claude.ai or ChatGPT?

You don't need a key. In the app, add a custom connector and paste this server address. The app will open an agency-os page asking you to sign in and approve it.

{{ ai.mcp_url }}

Any other app: create an access key

{% if ai.new_token %}
Your access key is ready. Copy it now: for your security it is shown only this once.

In your AI app, find its MCP or "connections" settings and add a new server with these values:

Server address (URL)
{{ ai.mcp_url }}
Header name
Authorization
Header value
Bearer {{ ai.new_token }}
Access key only
{{ ai.new_token }}

Some apps ask for the key on its own (use "Access key only"); others want the whole header value, which starts with the word Bearer and a space.

Setup examples for Hermes Agent, Claude Code and config files

Hermes Agent: add to ~/.hermes/config.yaml

mcp_servers:
  agency_os:
    url: {{ ai.mcp_url }}
    headers:
      Authorization: "Bearer {{ ai.new_token }}"

Claude Code: run in a terminal

claude mcp add --transport http agency-os {{ ai.mcp_url }} --header "Authorization: Bearer {{ ai.new_token }}"

Apps configured with a JSON file (Rook, Claude Desktop and others)

{"mcpServers": {"agency-os": {"url": "{{ ai.mcp_url }}", "headers": {"Authorization": "Bearer {{ ai.new_token }}"}}}}
